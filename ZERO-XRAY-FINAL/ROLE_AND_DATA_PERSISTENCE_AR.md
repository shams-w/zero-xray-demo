# ZERO X-RAY — الصلاحيات وحفظ بيانات الجهة

## الواجهات حسب الدور
- Platform Admin: إدارة الجهات والاشتراكات فقط.
- Entity Admin: الخدمات + مصادر البيانات + التكاملات + المستخدمون + سجل التدقيق + الإعدادات.
- Service Owner: التحليل + خدماته + الخدمات المنشورة، ويختار من مصادر/تكاملات الجهة الموجودة عند إنشاء الخدمة.
- Analyst: التحليل + المعايير + الخدمات، بدون نشر أو إدارة الجهة.
- Viewer: نظرة عامة + الخدمات + الخدمات المنشورة فقط.

الصلاحيات الحقيقية تظل مفروضة في الـBackend، وليس مجرد إخفاء عناصر الواجهة.

## المستخدمون
المستخدمون محفوظون في جدول `platform_users` داخل `server/data/runtime.db`.
إغلاق وإعادة تشغيل الـBackend لا يحذفهم. جلسات الديمو كذلك محفوظة في `demo_sessions`.

## ملفات Data Sources
عند رفع ملف، يحفظ ZERO X-RAY:
1. الملف الأصلي تحت `server/data/tenant_files/<tenant_id>/<source_id>/...`
2. metadata في جدول `data_sources` (اسم الملف، MIME type، الحجم، storage path)
3. النص المستخرج داخل configuration حتى يستخدمه التحليل.

كل lookup يظل tenant-scoped، لذلك معرفة source UUID لا تعطي جهة أخرى وصولاً للملف أو metadata.

## ربط الخدمة
الاختيارات تحفظ في:
- `service_data_sources`
- `service_integrations`

لذلك بعد Restart تظل الخدمة مرتبطة بنفس المعرفة والأنظمة.
